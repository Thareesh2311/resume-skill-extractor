## ✨ Features

- **Resume Upload:** Upload resumes in PDF, DOCX, and TXT formats.
- **Automatic Skill Extraction:** Automatically identifies technical skills from resume content.
- **Smart Categorization:** Organizes detected skills into different technical categories.
- **Interactive Dashboard:** Displays detected skill statistics and category-wise results.
- **Dynamic User Interface:** Futuristic interface with animations, glowing effects, and cinematic visual elements.
- **PDF Text Extraction:** Extracts text from PDF documents using PDF.js.
- **DOCX Processing:** Reads Microsoft Word documents using Mammoth.js.
- **Instant Results:** Processes documents directly in the browser.
- **Responsive Design:** Designed to work across desktop, tablet, and mobile devices.
- **Privacy Focused:** Resume processing happens locally in the browser. Resume files are not uploaded to a project backend.

---

## 🔒 Privacy & Security

Resume processing is performed directly in the user's browser.

- No project backend is required.
- Resume files are not sent to a project server.
- Extracted results are displayed in the browser.
- External JavaScript libraries are loaded through CDNs.

**Note:** This application performs text-based extraction. Scanned or image-only PDFs may require OCR support, which is not currently included.
